# 公開中の試作版です

2026年11月10日時点。Cloud Run（https://private-deployment.invalid）で公開しており、URL を開けばログインなしで使えます。本番運用の準備は完了していません。Google Cloud の実 API に接続し、検索・写真比較・衛星データの探索は動作しますが、不特定多数が使うサービスとしての運用は未検証です。

## どの場所でも使えるわけではありません

| 探し方 | 現在できること | 制限 |
| --- | --- | --- |
| 地名・地図から選ぶ | Google Places / Geocoding が解決できる場所を選択 | 未登録地点、名称が曖昧な場所、サービス提供範囲などでは解決できないことがある |
| 雰囲気から探す | Gemini が Google Maps の情報を参照し、候補と出典を返す | すべての場所で十分な候補が得られる保証はない。静かさや混雑は実測していない |
| 地名から写真を比べる | Commons で場所名・所在地・被写体・利用条件を確認した写真を取得 | 比較する写真は現在111地点。写真がなければ Maps 検索へ切り替え、理由を表示する |
| 自分の写真を比べる | 位置情報を除去した画像を Gemini Embedding 2 で解析し、Commons の111地点と、検索時に照合できた追加候補と比較 | 撮影場所は特定しない。解析できなければ選んだ特徴で並べる。写真は共有・保存しない |
| 衛星地図で範囲を選ぶ | 世界の登録地形56地点のうち、選択範囲から100 km以上離れた別の領域を探す | 登録地形と指定半径内の衛星標本を併用し、後者は領域で再比較して未分類と表示。全世界の網羅検索ではない。参照範囲は一辺40 km・900 km²以内。群島・ラグーン・環礁の種類や輪郭は確定しない |

衛星比較には2024年の Satellite Embedding V1 を使います。Google Maps で見えている航空写真そのものは解析しません。衛星埋め込みは陸地と浅い水域が対象で、深い海や極域などは比較できない場合があります。[Google のデータ仕様](https://developers.google.com/earth-engine/datasets/catalog/GOOGLE_SATELLITE_EMBEDDING_V1_ANNUAL)

3D地球儀、気候区分、2019年の観光統計による条件を追加しています。3D表示はブラウザーと端末の対応に左右されます。気候区分は現在の天気、観光統計は現在の人気や安全性を示しません。

## 公開中のサービスに残っている作業

- **API の利用制限と認証**：有料 API を呼ぶ経路に、利用者単位の認証・回数制限を追加する。現在の公開環境では、認証なしのリクエストも `/api/discover` の入力検証まで処理される（2026年11月10日に確認）。アップロードの同時処理は現在1プロセスあたり2件に制限しているが、公開サービスの不正利用対策には足りない。予算アラート、APIクォータ、想定負荷での費用も確認する。
- **Google 上の実行環境**：Cloud Run の実行用サービスアカウントが必要な権限だけを持つことを確認する。公開ドメイン、キーの制限、Secrets、送信元の設定も確認する。この文書の更新時には、Cloud Run の設定内容を確認していない。`.env.local` は公開しない。
- **依存パッケージとレスポンスヘッダー**：Next.js 16.3.4 には重大度 critical の勧告が3件あり、`npm audit` は 16.4.5 を修正版として示す。公開環境のレスポンスには CSP、HSTS、`X-Frame-Options`、`nosniff` がない（2026年11月10日に確認）。
- **データと運用**：Commons の候補を増やし、出典・利用条件の更新手順とキャッシュの保管先を決める。カタログと再利用可能な埋め込みは BigQuery に保存し、ローカルのコピーも持つ。複数インスタンスでの運用、データ更新や失敗からの復旧は未検証。リクエストの監視、エラー通知、API障害時の運用も用意する。
- **精度の検証**：季節・画角が異なる写真や、複数のラグーン・環礁・群島で、人による評価を行う。現在の順位は比較の手がかりであり、一致率ではない。衛星の平均特徴では失われる形や配置を扱うなら、範囲同士の比較や地形の輪郭を調べる処理が必要になる。
- **利用者への説明と確認**：画像の送信先と保存方針、画像解析に使える権利、匿名保存の制限を公開中の案内に反映する。Google ログインと端末間同期は実装済みだが、実際の Google アカウントでの確認が必要。公開するドメインは Firebase の承認済みドメインと API キーの参照元に追加する。実機の iPhone / Android、キーボード操作、スクリーンリーダー、低速回線で確認する。

Earth Engine はハッカソン・学習の非商用用途で登録しています。一般公開している現在の利用がこの登録の範囲に入るかを確認してください。商用化へ進むときも、実際の利用目的に合う登録と条件を確認してください。

## 動作確認と本番品質の判断を分けます

実 API と画面で確認した内容は [検証記録](VERIFICATION.md) に記載しています。ビルドやテストの成功だけで、本番公開の可否や地形判定の精度を保証するものではありません。

2026年11月9日更新：公開地点カタログは612地点、準備済みの Commons 写真は40地点、3×3の領域データを準備した地形は56地点です。動的な写真候補の取得と、半径150〜1,000 kmの衛星探索を追加しました。Commons は429時に取得を止めて待機し、利用できた写真だけで比較します。データ追加コマンドは再実行でき、公開写真と地形だけをキャッシュします。API制限下のカバレッジと、検索時間・費用・順位の人手評価は引き続き必要です。

検索の費用設定と国単位の参考指標は [SEARCH_IMPROVEMENTS.md](SEARCH_IMPROVEMENTS.md) に記載しました。50件の初期評価ケースは人による確認待ちです。500地点の写真検証が完了したとは扱わず、現時点で確認済みの111地点・112枚だけを準備済みとして数えます。人による確認は `npm run eval:review` の画面で進められます。

2026年11月10日更新：準備済みの Commons 写真は111地点・112枚です。カタログの612地点すべてに写真があるわけではありません。この写真の追加、検索結果への移動、絞り込みの折りたたみ、評価の匿名送信は作業ツリーの変更で、公開環境にはまだ反映していません。評価の匿名送信を公開環境で使うには、`npm run google:rules` で Firestore のルールも反映します。

同日、写真検索の結果の再利用と共有、実際の写真検索の記録（`npm run eval:record`）、英語表示を追加しました。これらも公開環境にはまだ反映していません。結果つきの共有は、Firestore のルールを反映するまで条件だけの共有になります。雰囲気からの検索は Google の利用規約により、結果を再利用・共有しません。
