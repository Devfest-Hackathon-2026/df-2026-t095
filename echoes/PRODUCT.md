# Elsewhere

<!-- impeccable:product-schema 1 -->

## Platform
web

## Stack
Next.js と React。Google Cloud の devfest-hackathon-hexagon に接続。アプリはローカルで実行し、将来の Firebase App Hosting / Cloud Run に備える。現在は公開しない。

## Users
好きな場所から、別の街や地域にある似た場所を探したい人。スマートフォンとPCの両方で使う。

## Product Purpose
場所を入力・選択し、風景、過ごし方、地形を手がかりに候補を探す。共通点と違いを確認し、気になる場所を保存する。

## Capabilities and Constraints
地図・場所の選択は Google Maps / Places、候補の説明は Maps に基づく Gemini を使用。地名からの写真検索は Wikimedia Commons の画像を Gemini Embedding 2 に送り、既存12地点のコレクション内で比較する。利用者は、解析に使える権利を確認した自分の写真もアップロードできる。アップロード写真は EXIF・GPS 情報を除去して Google に送り、このアプリでは画像とその埋め込みを保存しない。撮影場所は未指定として扱い、候補には Commons の写真を使う。Google Maps / Google Earth の画面画像は使わない。新しい出発点の写真は、場所名・所在地・被写体を照合する。地名からの検索で適切な写真や埋め込みがなければ Maps 検索へ切り替え、撮影場所未指定の写真では選んだ特徴だけで比較する。どちらも理由を表示する。順位を一致率として表示しない。

Earth Engine では、航空写真上の対角の2点または数値入力で参照範囲を選び、2024年の平均衛星特徴を、指定地域の周辺5〜50 kmの候補地点と比べる。地点の周辺100 mを参照する方法も残す。Google Maps の表示画像自体は解析しない。標高・傾斜・水域の観測を表示し、衛星データがなければ候補を作らず理由を伝える。地形の種類を確定する分類や、レグールの土壌判定は未実装。

Firestore は匿名ユーザーごとの保存と共有用の検索条件に使用する。写真や Google の場所の説明を保存データベースへ複製しない。Google アカウントでのログインと端末間同期は未実装。日本語は natural-japanese を参照し、平易で具体的に書く。

## Evidence on Hand
ユーザーの日本語の構想、ローカルを維持する指定、Google プロジェクトの指定、非商用利用と Earth Engine 登録済みの回答。実際の Google API 接続と Commons の写真ライセンスを確認した記録がある。校正された類似率や、地形分類の精度検証データはない。

## Product Principles
- 似ているところと、意味のある違いを説明する。
- 写真の観察と、雰囲気・静かさなどの解釈を分ける。
- 使えない処理と代わりの比較方法を明示する。
- 地名から探すときは、利用条件と出典を確認できる写真をアプリが用意する。自分の写真も、権利と送信先を確認してから使える。
- ローカルで使える状態を保ち、公開は別の依頼として扱う。
