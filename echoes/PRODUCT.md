# Elsewhere

<!-- impeccable:product-schema 1 -->

## Platform
web

## Stack
Next.js と React。Google Cloud の devfest-hackathon-hexagon に接続。Cloud Run で公開している。ローカルでも実行でき、Firebase App Hosting 用のひな型も残している。

## Users
好きな場所から、別の街や地域にある似た場所を探したい人。スマートフォンとPCの両方で使う。

## Product Purpose
場所を入力・選択し、風景、過ごし方、地形を手がかりに候補を探す。共通点と違いを確認し、気になる場所を保存する。

## Capabilities and Constraints
地図・場所の選択は Google Maps / Places、候補の説明は Maps に基づく Gemini を使用。地名からの写真検索は Wikimedia Commons の画像を Gemini Embedding 2 に送り、登録した612地点のうち、出典と被写体を確認できた111地点の写真で比較する。候補カタログと、公開写真・登録地形の埋め込みは BigQuery に保存し、利用できないときはローカルのコピーを使う。Cloud Vision API の信頼できるラベルと、Geminiによる地形・構図の見比べを補助信号に使う。利用者は、解析に使える権利を確認した自分の写真もアップロードできる。アップロード写真は EXIF・GPS 情報を除去して Google に送り、このアプリでは画像とその埋め込みを保存しない。撮影場所は未指定として扱い、候補には Commons の写真を使う。Google Maps / Google Earth の画面画像は使わない。新しい出発点の写真は、場所名・所在地・被写体を照合する。地名からの検索で適切な写真や埋め込みがなければ Maps 検索へ切り替え、撮影場所未指定の写真では選んだ特徴だけで比較する。どちらも理由を表示する。順位を一致率として表示しない。

Earth Engine では、航空写真上の対角の2点または数値入力で参照範囲を選び、2024年の平均衛星特徴を、世界の登録地形56地点のうち、比較元から100 km以上離れた別の領域と比べる。同じ参照範囲と近接した地点は除外する。地点の周辺100 mを参照する方法も残す。Google Maps の表示画像自体は解析しない。標高・傾斜・水域の観測を表示し、衛星データがなければ候補を作らず理由を伝える。地形の種類を確定する分類や、レグールの土壌判定は未実装。

気候区分は Beck et al. の1991〜2020年の Köppen–Geiger 分類を使い、同じ区分または指定した区分だけに絞れる。観光客が少なめの国・地域は、世界銀行の2019年の国際観光客数が100万人未満という条件で選ぶ。現在の人気・混雑・安全性を表す指標にはしない。

Google の3D地球儀とカメラ移動を使い、候補間の位置関係を見られる。動きを減らす設定では即時に移動する。

Firestore は Firebase Authentication のユーザーごとの保存、共有用の検索条件と写真検索の結果の ID、利用者が選んだときだけ送る匿名の評価に使用する。写真や Google の場所の説明を保存データベースへ複製しない。最初は匿名ユーザーで保存し、Google でログインすると保存を引き継いで端末間で同期する。日本語は natural-japanese を参照し、平易で具体的に書く。

## Evidence on Hand
ユーザーの日本語の構想、ローカルを維持する指定、Google プロジェクトの指定、非商用利用と Earth Engine 登録済みの回答。実際の Google API 接続と Commons の写真ライセンスを確認した記録がある。校正された類似率や、地形分類の精度検証データはない。

## Product Principles
- 似ているところと、意味のある違いを説明する。
- 写真の観察と、雰囲気・静かさなどの解釈を分ける。
- 使えない処理と代わりの比較方法を明示する。
- 地名から探すときは、利用条件と出典を確認できる写真をアプリが用意する。自分の写真も、権利と送信先を確認してから使える。
- ローカルで使える状態を保ち、公開環境への反映は別の依頼として扱う。

写真の入力は、専用のドロップエリアとファイル選択ボタンから行える。ドラッグ中の状態を視覚的に伝え、1枚ずつ受け付ける。選択・ドロップだけでは外部へ送信せず、従来と同じ権利確認と検索操作を経て解析する。

写真は登録候補に加え、景観の説明を手がかりに Maps で新しい候補を探し、Commons の被写体・場所・ライセンスを確認した写真を比較する。アップロード写真の景観説明は保存しない。

地形は登録地形と、指定した中心の半径150〜1,000 kmの衛星標本を組み合わせる。標本の上位から最大8領域を取り出し、比較元と同じ広さで再比較する。平均衛星特徴、3×3の配置、取得できた標高・傾斜・起伏・水域を使用し、衛星候補は未分類と表示する。取得失敗時の比較範囲を明示し、公開データのキャッシュを使う。


人口密度、水質統計、殺人発生率を国単位の参考条件として個別に選べる。2020〜2024年の公表値で、観測年と出典を表示する。地点ごとの水質・混雑・安全性は推定しない。新条件の不明値は、確認できた候補の後に残すことを既定とする。共有URLとブラウザーに条件を保持する。`ELSEWHERE_SAVE_COSTS` で新規探索・Vision・写真の確認件数を切り替え、初期設定は節約とする。公開写真の索引を一括で再利用し、複数の写真で比較できる。

画面は日本語と英語に対応する。Google Maps に基づく回答は表示する言語で生成し、翻訳で書き換えない。写真検索の結果は、登録カタログと Commons の写真だけで作ったものに限り、同じ条件の検索に24時間再利用し、共有リンクでも表示する。雰囲気からの検索の結果は、検索した本人にだけ表示する。
